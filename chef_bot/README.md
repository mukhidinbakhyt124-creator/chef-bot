# 👨‍🍳 Шеф Алибек — Telegram-бот для рецептов

ИИ-помощник, который предлагает блюда из продуктов, которые есть дома.

---

## 🚀 Быстрый старт

### 1. Получи токены

**Telegram Bot Token:**
1. Открой [@BotFather](https://t.me/BotFather) в Telegram
2. Отправь `/newbot`
3. Придумай имя и username боту
4. Скопируй токен (формат: `1234567890:AABB...`)

**Anthropic API Key:**
1. Зайди на [console.anthropic.com](https://console.anthropic.com/)
2. Перейди в API Keys → Create Key
3. Скопируй ключ (формат: `sk-ant-api03-...`)

---

### 2. Установи зависимости

```bash
pip install -r requirements.txt
```

---

### 3. Настрой переменные окружения

**Вариант A — через файл .env:**
```bash
cp .env.example .env
# Отредактируй .env и вставь свои токены
```
Затем загрузи перед запуском:
```bash
export $(cat .env | xargs)
```

**Вариант B — напрямую в терминале:**
```bash
export TELEGRAM_BOT_TOKEN="твой_токен_тут"
export ANTHROPIC_API_KEY="твой_ключ_тут"
```

---

### 4. Запусти бота

```bash
python bot.py
```

Бот запустится и будет ждать сообщений в Telegram. ✅

## 💬 Как пользоваться

| Действие | Пример |
|----------|--------|
| Список продуктов | `Яйца, лук, сыр, помидоры` |
| Выбор блюда | `Сделай рецепт омлета` |
| Уточнение | `Без мяса` / `Побыстрее` |
| Новый запрос | `/clear` или `/start` |

---

## 🛠️ Команды бота

- `/start` — приветствие и быстрые кнопки
- `/help` — справка
- `/clear` — сброс истории разговора

## ☁️ Деплой (опционально)

**На Railway.app (бесплатно):**
1. Загрузи папку на GitHub
2. Зайди на [railway.app](https://railway.app) → New Project → GitHub
3. Добавь переменные окружения в настройках
4. Railway сам запустит бота 24/7

**На VPS / сервере:**
```bash
# Запуск в фоне через screen
screen -S chef_bot
python bot.py
# Ctrl+A, D — выйти из screen
```
